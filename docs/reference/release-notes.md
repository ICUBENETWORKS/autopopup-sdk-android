# 9. 릴리스 노트

모든 버전의 최소 지원 버전은 Android 5.0(API 21)입니다.

## 1.1.1 (배포 예정)

**변경됨**

* 알림을 눌렀을 때 카드 메시지이고 다른 앱 위에 표시 권한이 있으면 카드를 펼치고, 그 외에는 메시지 링크를 열도록 변경(링크가 없으면 앱 실행). 권한이 없을 때 받은 알림도 같은 규칙을 따름

**고쳐짐**

* 알림이 여러 개일 때 이전 알림을 눌러도 마지막 알림의 링크가 열리던 문제

**보안**

* 다른 앱이 SDK의 팝업 표시 서비스를 실행하지 못하도록 차단
* 릴리스 빌드 로그에 서버 요청 내용, 푸시 토큰, 전화번호, 광고 ID가 남지 않도록 변경

## 1.1.0 (2026-11-16)

**추가됨**

* 토큰 없이 받을 수 있는 배포 저장소(`https://icubenetworks.github.io/autopopup-sdk-android/maven`)
* 메시지 정보에 광고 스플래시·광고 배너 항목을 받는 기능

**변경됨**

* 광고 화면을 상태 표시줄과 내비게이션 바를 가리지 않는 전체 화면으로 표시

## 1.0.8 (2026-11-16)

**추가됨**

* 서버 등록 때 기기 식별자 전송: 광고 ID, 광고 ID를 받을 수 없으면 같은 기기의 POPCON SDK 탑재 앱끼리 공유하는 서비스 식별자
* 광고 ID 권한(`AD_ID`)과 식별자 공유 리시버를 SDK 매니페스트에 추가(앱에 자동 병합)
* 화면 위 아이콘 오른쪽 위에 닫기(X) 버튼
* 아이콘·상단 배너를 처음 누르면 앱 실행

**변경됨**

* 다른 앱 위에 표시 권한이 없으면 화면 위 아이콘 대신 알림으로 표시하고, 알림을 누르면 첫 번째 카드의 이미지 링크를 열도록 변경

## 1.0.7 (2026-09-04)

**추가됨**

* 발신 번호 표시
* GA4 이벤트에 세션 정보 추가

## 1.0.6 (2026-06-12)
