# 6. 개인정보 처리방침과 Play 데이터 보안

POPCON SDK를 넣은 앱은 출시 전에 개인정보 처리방침과 Google Play 데이터 보안 양식을 고쳐야 합니다. 앱에서 무엇을 수집하는지 사용자에게 알리는 책임은 회원사에 있습니다.

> [!NOTE]
> 이 페이지는 작성 참고용이며 법률 자문이 아닙니다. 실제 문구는 회원사 법무·개인정보 담당 부서의 검토를 거쳐 적용합니다.

## SDK가 처리하는 정보

| 항목 | 쓰임 | 필수 |
|---|---|---|
| 푸시 토큰 | 메시지 전달 | 필수 |
| 광고 ID | 기기 식별, 중복 발송 방지, 광고 성과 측정 | 광고 ID를 받을 수 있을 때 |
| 서비스 식별자 | 광고 ID를 받을 수 없거나 사용자가 삭제·거부한 기기의 식별. 같은 기기의 POPCON SDK 탑재 앱끼리 공유 | 광고 ID 대신 |
| 앱 패키지명·버전, SDK 버전 | 앱 구분, 연동 상태 확인 | 필수 |
| 기기 모델, OS 버전, 통신사 | 표시 호환성 확인, 통계 | 필수 |
| 메시지 수신 확인, 표시·클릭·닫기 기록 | 발송 결과, 광고 성과 | 필수 |
| 전화번호 | 전화번호로 지정한 발송 | 선택 |

광고 ID와 서비스 식별자는 둘 중 하나만 서버에 보냅니다. 서비스 식별자는 SDK가 만든 무작위 값이며, 같은 기기에 POPCON SDK를 넣은 다른 앱이 있으면 그 앱과 같은 값을 씁니다. [법무 검토 후 확정: 광고 ID를 거부한 사용자도 서비스 식별자로 식별하는 것에 대한 고지 방식]

SDK는 메시지 표시·클릭·닫기·카드 넘김·머문 시간 같은 내부 이벤트를 Google Analytics(GA4)로도 기록합니다.

## 개인정보 처리방침

처리방침에 아래 내용을 추가합니다. [법무 검토 후 확정: 처리 위탁 기준 예시]

- 처리 위탁: 주식회사 팝콘앤미디어 / 위탁 업무: 팝콘메시지 발송·표시, 광고 게시·성과 측정
- 처리 항목: 위 표의 항목
- 회원사 간 정보 교차 활용은 하지 않습니다.

## Google Play 데이터 보안

Play Console의 데이터 보안 양식에 아래와 같이 표기합니다. [법무 검토 후 확정]

| Play Console 구분 | 데이터 유형 | 수집 | 목적 |
|---|---|---|---|
| 기기 또는 기타 ID | 광고 ID, 서비스 식별자, 푸시 토큰 | 수집함 | 앱 기능, 광고 또는 마케팅, 분석 |
| 앱 활동 | 앱 상호작용(메시지 표시·클릭) | 수집함 | 앱 기능, 분석 |
| 개인 정보 | 전화번호 | 사용 방식에 따라 수집 | 앱 기능 |
| 앱 정보 및 성능 | 진단 | 수집함(SDK 내부 이벤트를 GA4로 기록) | 분석 |

- 팝콘앤미디어는 회원사의 위탁을 받아 처리하므로 '공유'가 아닌 '수집'으로 표기합니다. [법무 검토 후 확정]
- SDK가 서버와 GA4로 보내는 데이터는 HTTPS로 암호화되어 전송됩니다.
- 앱이 광고 ID를 사용하므로 Play Console의 **광고 ID** 선언에서 "예"로 신고합니다.

## 다른 앱 위에 표시 권한 신고

Google Play는 다른 앱 위에 표시 권한을 쓰는 앱에 사용 목적을 물을 수 있습니다. 앱 심사 때 아래 내용을 바탕으로 설명합니다.

- 사용 목적: 사용자가 수신에 동의한 앱 소식을 화면 위 아이콘으로 알림
- 사용자가 아이콘을 누르면 앱이 열리고 화면 위에 카드 형태로 내용을 표시
