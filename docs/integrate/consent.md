# 수신 동의 연결

팝콘메시지는 **팝콘메시지 수신 동의**를 받은 사용자에게만 보낼 수 있습니다. 앱의 기존 알림·마케팅 동의와는 별개입니다. 휴대폰의 알림 권한이나 다른 앱 위에 표시 권한을 허용한 것도 수신 동의가 아닙니다.

## 동의 흐름

1. 팝콘메시지 수신 동의를 아직 받지 않은 사용자에게 동의 화면을 보여 줍니다.
2. 사용자가 동의하면 이어서 [권한](permissions.md)을 요청합니다.
3. 권한을 받으면 `enableAutoPopup()`을 호출해 SDK를 켭니다.
4. 사용자가 앱 설정에서 수신을 끄면 `disableAutoPopup()`을 호출합니다.

## 동의 화면 보여 주기

* **시점**: 설치 후 첫 실행 때 보여 줍니다. 이미 앱을 쓰던 사용자는 SDK를 넣은 버전으로 업데이트한 뒤 첫 실행 때 보여 줍니다.
* **화면**: SDK에는 동의 화면이 들어 있지 않으므로 앱에서 직접 만듭니다.
* **선택 동의**: 동의하지 않아도 앱의 기본 기능은 그대로 쓸 수 있어야 합니다.

아래 문구를 참고합니다. 화면 위에 표시되는 알림으로 받는다는 점과 제휴사 광고가 포함된다는 점이 들어가야 합니다.

**동의 문구 예시**

```text
앱 사용 중 화면 위에 표시되는 알림(팝콘메시지)으로 [앱 이름]의 소식과 제휴사 광고를 받습니다.

- 이용하는 정보: 앱 푸시 ID, 광고 ID(또는 서비스 식별자), 앱·기기 정보 (전화번호로 받는 경우 휴대전화번호)
- 이용 목적: 팝콘메시지 발송·표시, 중복 발송 방지, 광고 표시와 성과 분석
- 이용 기간: 동의 철회 또는 앱 삭제 시까지

동의하지 않아도 앱의 기본 기능은 그대로 이용할 수 있습니다.
모바일 네트워크에서는 데이터 요금이 발생할 수 있습니다.
```

실제 문구는 회원사 개인정보 담당 부서의 검토를 거쳐 적용합니다.

## 동의 값 전달하기

SDK에는 팝콘메시지 수신 동의 여부만 켜기·끄기로 전달합니다. 동의하면 `enableAutoPopup()`, 철회하면 `disableAutoPopup()`을 호출합니다. 꺼진 상태에서는 팝콘메시지가 와도 표시하지 않습니다.

**Kotlin**

```kotlin
val popcon = AutoPopupManager.getInstance(applicationContext)

// 팝콘메시지 수신 동의
popcon.enableAutoPopup(listener)

// 수신 동의 철회
popcon.disableAutoPopup()
```

**Java**

```java
AutoPopupManager popcon = AutoPopupManager.getInstance(getApplicationContext());

// 팝콘메시지 수신 동의
popcon.enableAutoPopup(listener);

// 수신 동의 철회
popcon.disableAutoPopup();
```

켜짐 상태는 기기에 저장되므로 앱을 다시 실행해도 유지됩니다.

## 수신 끄기 메뉴 만들기

팝콘메시지 카드 아래에는 수신거부 방법 안내가 함께 표시됩니다.

* 앱 설정(예: 설정 > 알림 > 팝콘 알림)에 팝콘메시지 수신 켜기·끄기 메뉴를 만듭니다.
* 끄면 `disableAutoPopup()`, 다시 켜면 `enableAutoPopup()`을 호출합니다.

광고성 메시지의 (광고) 표기와 카드 아래 수신거부 안내는 POPCON이 넣어 표시합니다. 앱에서 따로 넣지 않습니다.

## 로그아웃과 회원 탈퇴

수신 동의는 계정이 아니라 기기·앱 단위입니다.

* **로그아웃**: 수신을 그대로 둡니다.
* **회원 탈퇴, 동의 철회**: `disableAutoPopup()`을 호출해 수신을 끕니다. 이 기기에서는 이후 팝콘메시지가 표시되지 않습니다. 서버에 등록된 기기 정보의 삭제가 필요하면 [popcon@popcon.biz](mailto:popcon@popcon.biz)로 요청합니다.
